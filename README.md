EDI is short for Executable Disc Image, and is meant to be the executable version of an ISO. It is intended to be used for packaging apps and games. I know it's a little small, but that's the point, its meant to add functionality to the OS without having to take up much space.

Installing

`sudo install.sh` (in the directory of the install.sh file)

Opening the compiler

`edi_compiler`

Using the runner

`edi_runner path/to/edi/file [flags]`

To build your own version, all you have to do is download one of the versions you'd like to build, edit it, and then compile the C, and zip it up. You may need to chnge install.sh if you intend on adding new files or adding compatibility for other operating systems.
